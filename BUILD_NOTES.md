# BUILD NOTES — Aurtos Studio Website

## Overview
Complete production-grade Next.js 16 website for Aurtos Studio (Aurtos Technologies LLP), built with TypeScript, Tailwind CSS v4, Framer Motion, and full SEO infrastructure.

## Decisions & Defaults Used

### Technology
- **Next.js 16.2.4** with App Router (latest at time of build)
- **Tailwind CSS v4** (auto-installed by create-next-app, uses `@theme inline` syntax)
- **Framer Motion v12** for animations
- **lucide-react v1.11** for icons (note: `Instagram` icon not available in this version — custom SVG used instead)
- **No shadcn/ui CLI** — components built manually since shadcn may not fully support Tailwind v4 yet. All design patterns follow shadcn conventions.

### Blog System
- Using a **simple TypeScript data file** (`src/data/blog.ts`) instead of MDX/contentlayer for simplicity
- Blog posts contain markdown-like content that's rendered with basic regex parsing
- To migrate to MDX: create `/src/content/blog/*.mdx` files and integrate `@next/mdx` or `contentlayer`
- RSS feed not yet implemented (add via a `/feed.xml` route handler)

### Forms
- Forms currently log to console — **no backend connected**
- To connect: set up an API route at `/app/api/contact/route.ts` using Resend, SendGrid, or Formspree
- Form validation works fully via react-hook-form + zod

### Analytics
- GTM script included in root layout, gated by `NEXT_PUBLIC_GTM_ID` env var
- All tracking events (form_start, form_submit, whatsapp_click, phone_click, cta_click, service_card_click) are implemented but fire to console until GTM is configured
- Meta Pixel and GA4 should be configured inside GTM

### SEO
- Dynamic sitemap at `/sitemap.xml` (generated by Next.js route)
- Also configured `next-sitemap` as postbuild (generates to `/public/`)
- All pages have unique metadata, OG tags, Twitter cards, and canonical URLs
- JSON-LD schemas: Organization, WebSite, LocalBusiness, Service, FAQ, BreadcrumbList, Article
- `robots.txt` configured via Next.js route

### Design Tokens
- Colors, fonts, and design tokens are defined in `globals.css` using CSS custom properties
- Tailwind v4 `@theme inline` maps CSS vars to Tailwind utilities
- Fonts: Inter (body) + Space Grotesk (headings) via next/font

### Conversion Points
Every page has multiple conversion touchpoints:
1. Header "Get Quote" CTA
2. Mobile sticky bottom bar (Call / WhatsApp / Get Quote)
3. Floating WhatsApp button (all pages)
4. Exit intent popup (desktop, once per session)
5. Inline CTAs in every section
6. Service page inline contact form
7. Footer contact details

## Deployment

```bash
# Build and verify
npm run build

# Deploy to Vercel
npx vercel --prod

# Or self-host with PM2
npm run build
pm2 start npm --name "aurtos-studio" -- start
```

## Known Issues
1. The `next-sitemap` postbuild may conflict with the built-in Next.js `/sitemap.xml` route — you can disable one or the other
2. OG images are referenced but not yet created — generate or add manually
3. Google Map on contact page is a placeholder div — embed actual iframe
